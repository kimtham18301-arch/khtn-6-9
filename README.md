# KHTN 6–9 – Tự học Khoa học tự nhiên

Website tĩnh (HTML/CSS/JS thuần, không cần build) cho học sinh THCS: 42 bài, 126 câu luyện, bám Chương trình GDPT 2018 môn KHTN.

Chạy thử: mở `index.html` hoặc `python -m http.server` rồi vào http://localhost:8000.
Thêm bài: sửa các file trong `js/data/`. Đặc tả: `Dac-ta-website-KHTN.md`.
